About The Architecture 🏗️

This website is running inside an isolated Linux environment called an Alpine Nginx Container.

Because it is containerized, this exact same website can be moved to Google Cloud, Microsoft Azure, or a local Raspberry Pi without changing a single line of code. That is the true power of Docker.
